# seeds

INPUT:
• 25 geographic units in 5×5 grid
• Statewide: 48.8% D, 51.2% R
• Need: 5 districts

PROCESS:
Phase 1: Place 2 seeds in Democratic areas, 3 in Republican areas
Phase 2: Grow districts from seeds (units join matching districts)
Phase 3: Verify fairness

OUTPUT:
• 2 Democratic seats
• 3 Republican seats
• Matches statewide vote exactly!
• 0.4% efficiency gap
